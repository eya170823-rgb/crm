#### 22. 📘 이용 가이드 · 직원 매뉴얼  `P0 운영`

_화면 구성이 바뀌면 이 가이드도 자동으로 따라갑니다 (메뉴 순서 = 읽는 순서)_

- **무엇**: 이 매뉴얼 — 화면 구성이 바뀌면 자동으로 따라갑니다
- **언제**: 첫날 · 새 기능이 생겼을 때
- **순서**: 1) 메뉴 순서대로 읽기 → 2) 🖨 인쇄해 책상에
- 💡 P0=운영 중, P1=검증 후 공개, P2=예정

![📘 이용 가이드 · 직원 매뉴얼](guide.png)

- **🧮 계산기** — 계산기(취득세·양도세·중개보수·대출)
## 📌 예정(P2) — 버리지 않고 로드맵에 남긴 기능

- **전자서명(모두싸인·위드싸인)** — 상용 계약·과금 필요 — 계약서 작성기는 준비됨
- **온하우스 실제 공실망 연동** — 공개 API 없음 — 지금은 당근·오일장 수집분으로 대조
- **소유자 대조(등기부)** — 공개 건축물대장 API에 소유자 없음 — 등기부 열람(유료) 연동 시
- **노션 → 깃허브 문서 자동 동기화** — 저장소에 준비됨(docs-sync.yml) — 깃허브 비밀값 2개 등록 후 작동
- **광고비 배부·ROI / KPI·MBO / 급여·퇴직 / 메신저·전자결재 / 벌점** — 소규모 사무소엔 과잉 — 직원 늘면 단계별
- **매물까지 거리 표시(임장)** — 좌표(🗺 위치 계산) 쌓인 뒤
- **페르소나(대표/직원) 완전 분리 대시보드** — 지금은 타일·마스킹으로 구분

## 막히면

- "불러오기 0건" → 그 기기에 접속 링크를 다시 열기(토큰 재설정)
- 화면이 옛날 같으면 → 왼쪽 위 날짜 버전을 눌러 새 버전 확인
- 전화 카드가 안 뜨면 → ⚙️ 설정 → [전화 실시간 팝업] 체크 · 폰 웹훅(callRing) 설정 확인
- 그래도 안 되면 대표님께 (00_대표대시보드.md 와 이 문서를 Claude 에게)
